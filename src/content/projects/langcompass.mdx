**See how German themes, grammar, and communication goals connect before diving into the details.**

I have been learning German for some time, and one problem kept coming up: individual topics did not always feel connected when they appeared across different modules. When a familiar topic returned at a higher level, it was difficult to see what was new, how it related to what I had already learned, or where it fit in the wider curriculum.

That experience led me to build **LangCompass**, a free German learning explorer inspired by the clarity of a roadmap. It gives learners an overview of the curriculum, makes revisiting topics easier, and shows why related ideas return at different levels.

---

### **A Connected German Learning Map**

LangCompass covers **40 modules and 120 topics from A1.1 to B2.2**. Every module connects three complementary areas:

- **Themes** provide the vocabulary and real-world context.
- **Grammar** explains the structures used to express ideas.
- **Communication** turns that knowledge into practical goals.

Learners can scan the complete curriculum, focus on a CEFR sub-level, search across topic metadata, open a compact preview, and continue to a full lesson with examples, common mistakes, prerequisites, and related topics where available.

---

### **Optional Learning Tools with Chrome AI**

LangCompass includes practical use cases for task-specific AI. On supported desktop Chrome devices, learners can use optional tools to:

- Translate lesson content.
- Explain concepts in a different way.
- Generate additional examples.
- Summarize longer lessons.
- Check a German sentence and get feedback.

These tools use supported Chrome AI capabilities on the learner's device. There is no AI backend, local model server, account, or API key to configure, and the learning content sent to these tools does not need to leave the device.

---

### **Static-First by Design**

LangCompass is built with **Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, Zod, Fuse.js, and static JSON data**. It intentionally has no authentication, database, AI backend service, embeddings, or vector search. This keeps the core learning experience fast, accessible, and useful even when the optional AI capabilities are unavailable.
